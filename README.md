# ♔ Chess Pieces Recognition ♔

Приложение для распознавания шахматных фигур / Chess piece recognition app

---

## English

### Features
- Get FEN from a photo of a chess position
- Process chess game video to generate PGN
- Save recognition history
- Get a link to Lichess for further use

### Technologies
- TensorFlow Lite and YOLO for recognition
- Jetpack Compose for UI
- YOLO for image cropping

### Возможности
- Получение FEN по фотографии шахматной позиции

- Сохранение истории распознаваний
- Получение ссылки на Lichess для дальнейшего использования

### Технологии
- TensorFlow Lite и YOLO для распознавания
- Jetpack Compose для интерфейса
- YOLO для обрезки изображений
